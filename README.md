# EcoCatalyst Hub - Tunong Baroh Outdoor Management

Proyek ini adalah platform manajemen acara dan katalog program untuk Tunong Baroh Outdoor Management di Banda Aceh.

## Langkah Migrasi ke GitHub

Ikuti perintah berikut di terminal Firebase Studio Anda untuk mengunggah kode ke repositori baru:

1. **Inisialisasi Git Lokal:**
   ```bash
   git init
   ```

2. **Tambahkan File:**
   ```bash
   git add .
   ```

3. **Commit Pertama:**
   ```bash
   git commit -m "Initial commit: Tunong Baroh Hub"
   ```

4. **Atur Branch Utama:**
   ```bash
   git branch -M main
   ```

5. **Hubungkan ke GitHub:**
   ```bash
   git remote add origin https://github.com/Xpurple27/EcoCatalyst_TunongBaroh_Event_Organizer.git
   ```

6. **Unggah Kode:**
   ```bash
   git push -u origin main
   ```

## Teknologi yang Digunakan
- **Framework:** Next.js 15
- **UI:** ShadCN UI & Tailwind CSS
- **Database & Auth:** Firebase (Firestore & Auth)
- **AI:** Genkit
